# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, and keep criticism about the work.

The roasts are for projects, never for people. The same goes for issues and pull requests.

Report unacceptable behavior to the maintainers through a private [security advisory](https://github.com/0xuser64bit/job-not-finished/security/advisories/new) if it needs privacy, or by opening an issue otherwise.
